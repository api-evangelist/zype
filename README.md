Zype is an API-first video content management and streaming platform used by enterprises and media companies to run OTT apps, FAST and linear channels, and global video distribution. The platform spans a video CMS and CRM, cloud encoding, multi-CDN delivery, AI-assisted metadata, transcription and translation, SSAI advertising and DRM, subscription and transactional monetization, consumer entitlements, TV Everywhere authentication, cloud playout scheduling with XMLTV and platform EPG export, and a no-code app builder for web, mobile and connected TV. Zype publishes fifteen OpenAPI 3.0.1 definitions covering 317 operations, an RFC 8414 OAuth authorization server advertising 148 scopes, and a first-party MCP server. Zype is a Backlight business.

**Areas:** Video · Streaming · OTT · Video CMS · FAST · Linear TV · Playout · Monetization · Live Streaming · Analytics · Media and Entertainment · DRM

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Zype: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
